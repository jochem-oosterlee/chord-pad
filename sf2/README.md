# Sample / SoundFont files

## FluidR3_GM.sf2

- Source: <https://musical-artifacts.com/artifacts/738> (mirror of the original SF2)
- Original author: Frank Wen (2000)
- License: **CC-BY 3.0** (Creative Commons Attribution)
- Size: ~148 MB
- Tracked via Git LFS

A full General MIDI SoundFont bank. We use a handful of its presets
(piano, e-pianos, organ, strings, choir, vibes, pad) as the audio source
for our instruments — both the dry samples and the loop / envelope /
filter metadata that lets notes sustain properly.
